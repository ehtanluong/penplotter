# BankXY Mk1.1 - DIY A2 sized FluidNC CoreXY Pen Plotter

BankXY (homage to Banksy) is my first iteration of a large format pen plotter based on the CoreXY kinematic system, popularized in modern consumer 3D printers. It is a relatively simple build, with mainly 3D printed parts and 2020 & 2040 aluminium extrusion for the gantry. The firmware is even simpler, thanks to FluidNC CNC motion control.

## Features
- Fully custom mechanical design in Onshape
- Mostly 3D printed parts
- MKS DLC32MAX CNC controller board with ESP32-S3
- FluidNC motion control firmware for web browser interface and easy configuration with .yaml file
- xxxmm x yyymm plottable area (A2 sized)
- xxxmm/s speed
- xxxmm/ $s^{2}$ acceleration
- Automatic XYZ homing sequence 
- Simple fine belt tensioning
- xxxx x yyyy px resolution
- Recycled electronics from broken 3D printer
